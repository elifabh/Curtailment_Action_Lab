# Judging criteria — v5 evidence

The official site lists six labels below. This table is an evidence map, not a predicted judge score or a claim of satisfying every requirement. Microsoft AI use still requires the live event connection. The attachment containing event-specific instructions was not part of this ZIP.

| Official criterion | Demonstrable support | Honest boundary |
|---|---|---|
| Innovation | Offer → physical counterexample → retain/switch/withdraw → data request in one inspectable workflow. | Existing tools cover curtailment and flexibility analysis; LLM falsification and robust optimisation are prior art. Integration hypothesis, not a first-ever invention. |
| Scalability | Precomputed numerical records separated from fast decision queries; stable input schema, source hashes, measured workload. | One prepared network, eight sites and eight conditions; no multi-network/cloud scaling benchmark. More sites require valid network data and new calculations. |
| Technical difficulty | RAW conversion audit, scoped AC checks, paired demand controls, 288 new physical solves, Python/JS parity, bounded function calls. | Partial controls/ratings remain; no full operational-security certificate or multi-period dispatch. |
| Presentation | Four-tab English product, PDF handoff, current editable slides, demo path and source notes. | Live delivery and device/browser rehearsal are still the presenter's task. |
| Deemed success | A working conditional decision demo; nontrivial physical location differences; explicit withdrawal and switching; authored policy and contract tests. | Test-set success is not measured avoided curtailment or established AI benefit. |
| Business/Environmental impact | A purchaser can see whether an assumed offer fits budget and why its benefit fails under stress. Modelled wind acceptance can rise. | Prices/duration/offers are hypothetical; no customer willingness-to-pay, field MWh, emissions, settlement or profit claim. |

Source: https://hacktheclimate.io/ (official public brief reviewed on 28 September 2026). The source brief does not establish that all operational pilot work must be completed for a decision-support entry. Do not replace any event-specific final instructions with this interpretation.
