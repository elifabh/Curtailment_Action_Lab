# Delivery status — v4

This package is a local public-data planning demonstration. It is not an approved dispatch service or a measured field-saving product.

- **50 application tests passed**, covering API, numerical reference, agent contracts, stored study and conditional value rules.
- **Six Irish numerical/mutation checks passed**, including deliberately corrupted states.
- **40 DOM/HTTP/offline flow checks passed**, including all four tabs, 60 study conditions, eight candidate rows, positive and negative value examples, energy blocking, exports and selecting the best portfolio point. These are not rendered-browser visual checks.
- **457 actual physical evaluations** support the extended study. 141 passed all implemented snapshot gates; 316 were excluded and retained. High-wind points beyond the checked model limits were deliberately explored.
- The primary grid contains **38 positive, 20 neutral, zero negative and two blocked paired comparisons**. These are deterministic model conditions, not independent field trials or a success probability.
- The eight-candidate screen finds **68.359375 MW** accepted wind at bus 1701 versus **47.65625 MW** at the existing comparison point: **20.703125 MW** additional acceptance. It exceeds the nearest-point rule by **6.640625 MW**. Full screening uses more calculations; no equal-budget AI superiority is claimed.
- Source preparation, placeholder-like ratings, ideal-tie allocation and fixed-control limits remain explicit. Demand-stress failures are not erased.
- The commercial calculator uses entered assumptions and the selected physical record. It does not infer actual prices, a feasible chronological schedule, customer profit or annual savings.
- **Live Azure AI remains untested.** The adapter, contracts and local candidate baseline are supplied. Credentials and the actual event deployment are needed for the live test.
- **Current presentation preparation remains deferred.** The retained external deck/PDF/scripts are v2 materials, not an updated v4 presentation.
