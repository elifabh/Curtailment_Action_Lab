# Data archive status in v3

The Irish source RAW file remains original public data. Older Irish result files in this directory and `audit/` are retained as historical diagnostics. Their old rating/control treatment was superseded; they must not be used to claim validated wind savings. They are not selectable as active comparisons in v3.

The current Irish study is `validation/conditional_flex_study.json`, generated by the source audit and equations in `irish_audit/`. `recorded.json` contains the current exact application requests only. Reference-network records remain a separate experiment.
